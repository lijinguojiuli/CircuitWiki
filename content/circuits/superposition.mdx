## 1. 核心概念

在线性电路中，同一支路的电压或电流，等于各独立电源单独作用时产生的响应的代数和。每次保留一个独立源或一组独立源，最后按统一的参考方向合并结果。

其余独立电压源置零为短路，独立电流源置零为开路。电阻与线性受控源的控制关系始终保留，受控源的控制量在每个分电路中重新计算。

<Tip>
  先叠加电压、电流，再用总响应计算功率。功率不是可以直接相加的线性响应。
</Tip>

### 常见可以使用的情况

| 情况                             | 怎样使用                           | 需要注意                                       |
| -------------------------------- | ---------------------------------- | ---------------------------------------------- |
| 多个直流独立源驱动电阻网络       | 分别求目标电压、电流，再带符号求和 | 电阻保持线性，参考方向一致                     |
| 同频正弦源驱动线性 RLC 网络      | 用该频率的阻抗在相量域求和         | 使用同一频率、同一峰值或有效值约定             |
| 不同频率的独立激励               | 各频率分别求解，再还原瞬时量相加   | 不能把不同频率的相量直接相加；各频率下阻抗不同 |
| 同时含独立源和线性受控源         | 只拆分独立激励，保留每个受控关系   | 控制系数不变，控制量随分电路改变               |
| 线性动态电路的初始储能与外部激励 | 零输入响应与零状态响应相加         | 初始条件只能正确分配一次，不能重复加入         |

一般非线性电路不能直接使用。若题目已指定固定工作点的线性小信号模型，可对该线性模型应用叠加。

### 为什么功率不能直接叠加

同一个电阻中，总电流 i=i′+i″，因此：

<Formula latex={"p=R(i'+i'')^2=R(i')^2+R(i'')^2+2Ri'i''"} />

分电路功率之和只有前两项，遗漏了**交叉项 2Ri′i″**。用 p=ui 展开时也会出现 u′i″ 和 u″i′。电压、电流可以线性叠加，但它们的乘积或平方一般不能。

<Example title="用10 Ω电阻看出遗漏的交叉项">

两个独立源单独作用时，同一电阻的电流分别为同方向1 A、2 A。先叠加得总电流3 A。

<Formula latex={"p=10(1+2)^2=90\\,\\mathrm W"} />

<Formula latex={"p'+p''=10\\times1^2+10\\times2^2=50\\,\\mathrm W"} />

少掉的40 W正是交叉项。正确答案为90 W。

</Example>

<Warning>
  某些特殊情况下交叉项恰好为零；不同频率分量在合适的平均区间内正交时，平均功率也可能按分量相加。这需要额外条件，不能作为“功率普遍满足叠加定理”的依据。
</Warning>

## 4. 解题步骤

1. 确认使用线性电路或题目指定的线性模型。
2. 固定目标电压、电流的参考方向。
3. 每次保留一个独立源或一组独立源，其余独立源置零。
4. 保留电阻与受控源，求当前分电路的控制量及响应。
5. 带符号叠加电压、电流，最后计算功率。

## 6. 典型例题

<Example title="先求R₂电流，再求吸收功率">

**题目：** US=12 V，IS=1 mA，R₁=2 kΩ，R₂=4 kΩ。求R₂中向下的电流与功率。

**电压源单独作用：** 电流源开路，两个电阻串联。

<Formula latex={"i_2'=\\frac{12}{2000+4000}=2\\,\\mathrm{mA}"} />

**电流源单独作用：** 电压源短路，R₁、R₂并联分流。

<Formula latex={"i_2''=1\\times\\frac2{2+4}=\\frac13\\,\\mathrm{mA}"} />

**叠加电流，再计算功率：**

<Formula
  latex={
    "i_2=\\frac73\\,\\mathrm{mA},\\quad p_2=4000\\left(\\frac7{3000}\\right)^2\\approx21.778\\,\\mathrm{mW}"
  }
/>

**最终答案：** 电流约2.333 mA，功率约21.778 mW。若先算分功率再相加，只会得到16.444 mW，遗漏交叉项5.333 mW。

</Example>

## 7. 常见错误

<Warning>

- 电压源、电流源置零方式相反。
- 关闭独立源时，连同旁边的电阻一起删掉。
- 把受控源也关闭，或把完整电路的控制量数值固定带入每个分电路。
- 丢失负号，或直接相加功率。
- 将不同频率的相量直接相加。

</Warning>

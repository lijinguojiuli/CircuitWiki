## 1. 核心概念

线性含源一端口对外部负载的作用，可以用一个开路电压 uoc 与一个输入电阻 Req 的串联组合表示。等效保持端口电压、电流关系，特别适合负载变化时的计算。

规定端口A对B为正，输出电流i从A流向外部负载。

<Tip>先移去负载并固定端口。负载RL不计入原网络的Req。</Tip>

### 两种解法怎样选择

| 方法                       | 计算步骤                                       | 适合情况                                   |
| -------------------------- | ---------------------------------------------- | ------------------------------------------ |
| 方法一：开路电压＋输入电阻 | 移去负载求uoc；独立源置零，化简或加测试源求Req | 置零后的电阻易化简，或含受控源需要测试源法 |
| 方法二：开路电压＋短路电流 | 分别计算uoc与isc，再求Req=uoc/isc              | 短接端口后容易计算，且isc有限、非零        |

### 输入电阻的计算

[先读输入电阻的定义、端口与Req含义](/learn/input-resistance)。

独立源置零后，从A-B看向网络内部：只有电阻时可以串并联、星三角化简；含受控源时必须保留控制关系，并可在端口加测试源。

<Formula
  latex={"R_{in}=R_{eq}=\\frac{u_t}{i_t}"}
  description="教材式（2-12）的测试源写法：it定义为流入网络正端的电流。"
/>

也可加测试电流再求电压。测试电流it的方向，与端口输出电流i的方向约定不同。

<Warning>
  完整含源网络某个带载点的u/i通常不是Req。若uoc=isc=0，不能用0/0求电阻，应使用测试源法；仅含线性受控源而无独立源的网络就是常见情况。
</Warning>

## 4. 解题步骤

1. 移去负载，固定A-B端口及uoc、isc的方向。
2. 开路求uoc。端口电流为0，不代表内部每个元件电流为0。
3. 方法一求输入电阻，或方法二求isc后取比值。
4. 构造uoc串联Req的等效网络，重新接入负载。
5. 用另一种方法或端口KCL交叉检查。

## 6. 典型例题

<Example title="同一分压网络，用两种方法求解">

**题目：** US=12 V，上臂R₁=2 kΩ，下臂R₂=4 kΩ，负载从A接到B。求等效参数，以及RL=2 kΩ时的负载电流、电压。

**共同步骤——开路电压：** 移去负载，原网络R₂仍保留。

<Formula latex={"u_{oc}=12\\frac4{2+4}=8\\,\\mathrm V"} />

**方法一——输入电阻：** 电源短路后，R₁、R₂都跨在A-B之间，为并联。

<Formula
  latex={
    "R_{eq}=R_1\\parallel R_2=\\frac{2\\times4}{2+4}=\\frac43\\,\\mathrm{k\\Omega}"
  }
/>

**测试源核验：** 加ut=1 V，测试电流流入原网络。

<Formula
  latex={
    "i_t=\\frac1{2000}+\\frac1{4000}=0.75\\,\\mathrm{mA},\\qquad R_{in}=\\frac1{0.00075}\\approx1.333\\,\\mathrm{k\\Omega}"
  }
/>

**方法二——短路电流：** 短接A-B，R₂电压为0，isc由US与R₁决定。

<Formula
  latex={
    "i_{sc}=\\frac{12}{2000}=6\\,\\mathrm{mA},\\qquad R_{eq}=\\frac8{0.006}\\approx1.333\\,\\mathrm{k\\Omega}"
  }
/>

**重新接负载：**

<Formula
  latex={
    "i_L=\\frac8{(4/3+2)\\times1000}=2.4\\,\\mathrm{mA},\\qquad u_L=4.8\\,\\mathrm V"
  }
/>

**最终答案：** uoc=8 V、isc=6 mA、Req≈1.333 kΩ；两种方法一致。负载电流2.4 mA、电压4.8 V。

</Example>

<Example title="含受控源时的测试源法">

1 kΩ电阻与受控电流源并联在A-B之间，受控电流i=guₓ，方向A→B。uₓ就是A对B电压，g=0.5 mS。网络没有独立源。

<ControlledTestDiagram />

开路、短路响应均为0，不能取0/0。加ut=1 V，保留受控源，由uₓ=ut得：

<Formula
  latex={
    "i_t=\\frac1{1000}+0.0005\\times1=1.5\\,\\mathrm{mA},\\qquad R_{eq}=\\frac1{0.0015}\\approx666.67\\,\\Omega"
  }
/>

若错误删除受控源，会误算成1 kΩ。

</Example>

## 7. 常见错误

<Warning>

- 将带载电压当成开路电压，或开路时连原网络R₂也移去。
- 短路后仍让被短接电阻保有非零电压。
- 将负载RL算入原网络Req，或把受控源删除。
- 不检查isc是否为0就套uoc/isc。
- 混用输出电流方向与测试源流入电流方向。

</Warning>

## 1. 核心概念

实际电源常用两种线性模型：电压源与电阻串联，或电流源与电阻并联。满足参数与方向关系时，它们对外部负载的端口伏安特性相同，可以互相转换。

等效的是整个含源支路，不是单独把一个理想电压源换成理想电流源。

<Tip>先固定参考方向，再写元件关系和端口方程。</Tip>

转换前后R保持不变。电流源的正方向从电压源负端指向正端；端口A、B必须一一对应。R单位Ω，US单位V，IS单位A。

### 先分清：源与源、源与电阻怎么组合

以下结论针对理想独立源组成的完整二端组合，A、B端口保持不变；串联中点不再引出其他支路。这里u取A对B，i取从A流向外部负载的输出电流，电流源箭头指向A。

| 组合               | 对外保留什么 | 仍存在的内部量                                 |
| ------------------ | ------------ | ---------------------------------------------- |
| 电压源与电流源并联 | 电压源，u=US | 电流源仍输出IS，电压源电流随内部和外部支路改变 |
| 电压源与电流源串联 | 电流源，i=IS | 电压源仍提供US，电流源端电压随外电路改变       |
| 电压源与电阻并联   | 电压源，u=US | 电阻电流US/R、功耗US²/R仍存在                  |
| 电流源与电阻串联   | 电流源，i=IS | 电阻压降IS R、功耗IS²R仍存在                   |

<Warning>
  记忆：并联由理想电压源固定电压，串联由理想电流源固定电流。这是整体对外等效，不能据此把原网络的内部电流、压降或损耗当成0。
</Warning>

**代入看一遍：** 5 V电压源与2 mA电流源并联，端口仍为5 V；串联时端口电流仍由2 mA电流源规定。5 V源并联1 kΩ，电阻内部消耗25 mW；2 mA源串联1 kΩ，电阻仍有2 V压降、4 mW损耗。

**不要与实际电源变换混淆：** 电压源串联R才可换成电流源并联R；电压源并联R只是对外等效为原电压源。电流源串联R也不能照套US=IS R，把整个组合当作一个电压源。

<Warning>
  两个理想电压源并联时，电压必须相等、极性一致，内部电流分配不一定能唯一确定；两个理想电流源串联时，电流必须相等、方向一致，各源分担电压不一定能唯一确定。不能把互相矛盾的理想约束取平均。
</Warning>

补充依据：教材§1-6的理想源约束、§2-5的源组合与§2-6的端口等效；上表按KCL/KVL推得。

## 4. 解题步骤

1. 圈定电压源＋串联电阻，或电流源＋并联电阻的完整二端组合。
2. 固定端口A、B与电压极性、输出电流方向。
3. 按IS=US/R或US=RIS换算，保留相同电阻。
4. 检查控制量或外部接线没有被移动、消去。
5. 接回负载，核对端口电压、电流。

## 6. 典型例题

<Example title="同一负载，用两种模型验算">

**题目：** US=12 V，R=3 kΩ，负载RL=6 kΩ。求负载电流与电压，再转成电流源模型检查。

**思路：** 串联模型直接用欧姆定律；并联模型先换成IS=4 mA，再分流。

<Formula
  latex={
    "i_L=\\frac{12}{3000+6000}=\\frac43\\,\\mathrm{mA},\\quad u_L=8\\,\\mathrm V"
  }
/>

<Formula
  latex={
    "I_S=\\frac{12}{3000}=4\\,\\mathrm{mA},\\quad i_L=4\\frac3{3+6}=\\frac43\\,\\mathrm{mA}"
  }
/>

**最终答案：** 两种模型都得到1.333 mA、8 V。内部元件的电流、功率分布不必相同：端口开路时，串联模型的R无电流，电流源模型的R仍流过4 mA。

</Example>

## 7. 常见错误

<Warning>

- 只换电源，漏掉串联或并联电阻。
- 方向反了却仍把数值取正。
- 把电压源串联任意不相邻电阻，或把非并联电阻强行纳入转换。
- 受控源变换时丢失控制量所在支路；控制关系必须保留。

</Warning>

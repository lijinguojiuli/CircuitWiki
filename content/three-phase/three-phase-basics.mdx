## 1. 核心概念

三相电路由三相电源、输电线路和三相负载组成。对称三相电源的三相正弦电压同频、等幅，初相依次相差120°。

以 A 相为参考，正序为 A→B→C。电源或负载可以采用 Y 或 Δ 连接；Y 连接的中心为中性点 N，负载中性点常写 N′。

<Tip>先识别连接方式、参考方向和给定量的单位，再选公式。</Tip>

## 3. 核心公式

<Formula
  latex={
    "u_A=\\sqrt2 U\\cos\\omega t,\\quad u_B=\\sqrt2 U\\cos(\\omega t-120^\\circ),\\quad u_C=\\sqrt2 U\\cos(\\omega t+120^\\circ)"
  }
  description="p.301：正序对称三相电压，U 为每相有效值。"
/>

<Formula
  latex={
    "\\dot U_A=U\\angle0^\\circ,\\quad\\dot U_B=U\\angle(-120^\\circ),\\quad\\dot U_C=U\\angle120^\\circ"
  }
  description="p.301：对应的有效值相量。"
/>

<Formula
  latex={"\\dot U_A+\\dot U_B+\\dot U_C=0"}
  description="p.302：对称三相电压的相量和为零。"
/>

大写 U 为有效值，带点字母为相量，小写 u 为瞬时量。三相三线制有三条端线；三相四线制另有中性线。中性线与保护地线是不同用途的导线，本节图中的 N 不代表接地符号。

## 4. 解题步骤

1. 辨认 A、B、C 三相以及电源、负载中性点。
2. 检查电源是否同频、等幅并相差120°。
3. 确定正序或负序，并统一电压、电流参考方向。
4. 标明电源与负载分别采用 Y 还是 Δ。
5. 记录给定的是线电压还是相电压，再进入计算。

## 6. 典型例题

<Example title="判断一组三相电源是否对称">

**题目：** 三相相量为100∠10°、100∠−110°、100∠130° V。是否对称？相序是什么？

**思路：** 幅值相同；以第一相为参考，后两相分别滞后120°与超前120°。

**计算步骤：**

<Formula
  latex={
    "\\dot U_A+\\dot U_B+\\dot U_C=100e^{j10^\\circ}(1+e^{-j120^\\circ}+e^{j120^\\circ})=0"
  }
/>

**最终答案：** 这是一组正序对称三相电源。共同增加10°初相位，不改变相位差与对称性。

</Example>

## 7. 常见错误

<Warning>

- 把三个同相的正弦电压称为对称三相。
- 将电源中性点 N 与负载中性点 N′ 无条件当作等电位。
- 把中性线与保护地线当成同一概念。

</Warning>

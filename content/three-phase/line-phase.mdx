## 1. 核心概念

线电压是两条端线之间的电压，线电流是端线中的电流。相电压和相电流描述电源或负载的每一相。它们的关系取决于 Y、Δ 连接，不能仅凭“三相”二字就套用√3。

本页使用正序、教材所示参考方向和对称条件。Uₗ、Iₗ 简写线有效值，Uₚ、Iₚ 简写相有效值；带点的符号包含相位。

<Tip>先识别连接方式、参考方向和给定量的单位，再选公式。</Tip>

### 本小节教材要点

**概念与条件：** Y中线电流就是相电流，线电压由相电压相减；Δ中线电压就是相电压，线电流由相邻支路电流相减。对称正序时另一项有√3倍与±30°关系；不对称时保留一般相量差。

<Formula
  latex={
    "Y:\\ U_l=\\sqrt3U_p,\\ I_l=I_p;\\quad\\Delta:\\ U_l=U_p,\\ I_l=\\sqrt3I_p"
  }
  description="教材§12-2（本节起始书页303）；按教材参考方向整理的教学写法。"
/>

**怎样使用：** Y记线电压超前对应相电压30°；Δ记线电流滞后对应相电流30°，前提是教材正序与参考方向。

**代入示例：** 线电压380 V时Y相电压219.4 V，Δ相电压380 V；Δ相电流10∠0° A时A线电流17.32∠−30° A。

<Warning>只乘√3而漏掉30°，或把不对称支路电流套成同一倍数。</Warning>

## 3. 核心公式

<Formula
  latex={"\\dot U_{AB}=\\dot U_A-\\dot U_B=\\sqrt3\\dot U_A\\angle30^\\circ"}
  description="教材式（12-1）：正序对称 Y，线电压超前对应相电压30°。"
/>

<Formula
  latex={
    "\\dot I_A=\\dot I_{AB}-\\dot I_{CA}=\\sqrt3\\dot I_{AB}\\angle(-30^\\circ)"
  }
  description="按教材式（12-2）省略负载端撇号：正序对称 Δ，线电流滞后对应相电流30°。"
/>

记幅值关系时，先写出连接方式：Y 的线电流等于相电流；Δ 的线电压等于相电压。带√3的另一项还伴随30°相位变化。

| 对称正序连接 | 有效值关系      | 相位关系          |
| ------------ | --------------- | ----------------- |
| Y            | Uₗ=√3 Uₚ，Iₗ=Iₚ | UAB 比 UA 超前30° |
| Δ            | Uₗ=Uₚ，Iₗ=√3 Iₚ | IA 比 IAB 滞后30° |

### 使用示例

Y 负载端线电压为380 V，则相电压为380/√3≈219.4 V，通常近似220 V。若Δ相电流为10∠−20° A，则对应线电流为17.32∠−50° A。

## 4. 解题步骤

1. 判断正在讨论电源端还是负载端。
2. 判断该端是 Y 连接还是 Δ 连接。
3. 确认给定量是线值还是相值。
4. 先换算幅值，再按正序与参考方向处理±30°。
5. 使用相量相减核对，不对称情况保留一般差式。

## 7. 常见错误

<Warning>

- 把Y和Δ的线、相关系互换。
- 只乘√3，漏掉相位变化。
- 相序或参考方向改变后，仍机械沿用同一个±30°。
- 负载不对称时仍用 Iₗ=√3 Iₚ；应分别作相量相减。

</Warning>

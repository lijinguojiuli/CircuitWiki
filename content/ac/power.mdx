## 1. 核心概念

正弦稳态中的瞬时功率随时间变化。一个周期内的平均功率称为有功功率P；无功功率Q描述电源与储能元件之间的能量往返；视在功率S=UI描述电源和设备所需承担的电压、电流规模。三者单位分别为W、var、VA。

功率计算采用有效值。先确定电压、电流的关联参考方向，再求相位差φZ=φᵤ−φᵢ；感性负载Q为正，容性负载Q为负。复功率的统一算法在下一小节展开。

### 本小节教材要点

**概念与条件：** 瞬时功率含平均分量与两倍频振荡分量。有功P表示平均能量转换，无功Q描述储能往返，视在S=UI。功率因数λ=cosφZ。

<Formula

补偿减少电源侧无功与电流，不改变负载的有功需求。需要进一步计算时，进入[功率因数与补偿专题](/learn/power-factor#capacitor-compensation)。

</SecondaryTopic>

**怎样使用：** U、I用有效值；先判感性Q>0或容性Q＜0，再算P/Q/S与补偿量。

**代入示例：** P=1 kW、U=220 V、cosφ由0.8提高到1，电源电流由5.682 A降至4.545 A；50 Hz所需并联C约49.33 μF。

<Warning>
  把提高功率因数说成减少负载有功功率，或把峰值代入有效值功率式。
</Warning>

## 3. 核心公式

<Formula
  latex={"P=UI\\cos\\phi_Z,\\quad Q=UI\\sin\\phi_Z,\\quad S=UI"}
  description="第5版 p.235–236：有功、无功、视在功率。"
/>

<Formula
  latex={"\\overline S=\\dot U\\dot I^{*}=P+jQ"}
  description="第5版 p.238：复功率使用横线标记，电流相量取共轭。"
/>

U、I 均为有效值，φZ=φᵤ−φᵢ。P 单位 W、Q 单位 var、S 和复功率单位 VA。S 是实数视在功率，带横线的 S 是复功率，不能将复功率误当成相量。

<aside className="book-reference">
  教材依据：《电路》第5版 §9-4、§9-5，书页 233–239。以下数字示例为本站原创。
</aside>

### 先读懂符号

P 是平均消耗的有功功率；Q 是无功功率；复功率的实部与虚部分别为 P、Q。U、I 必须用有效值。

<div className="formula-usage">

### 使用示例：由有效值和相位差求功率

**什么时候用：** U=100 V、I=2 A，电压超前电流 60°。

**代入计算：**

<Formula latex={"P=100\\times2\\cos60^\\circ=100\\,\\mathrm W"} />

<Formula latex={"Q=100\\times2\\sin60^\\circ\\approx173.205\\,\\mathrm{var}"} />

<Formula
  latex={
    "\\overline S=100+j173.205\\,\\mathrm{VA},\\qquad S=UI=200\\,\\mathrm{VA}"
  }
/>

**结果怎么看：** 复功率的模为视在功率，不能直接用 P+Q 算视在功率。Q 为正表示此处负载呈感性。

</div>

## 4. 解题步骤

1. 功率计算采用有效值。先确定电压、电流的关联参考方向，再求相位差φZ=φᵤ−φᵢ；感性负载Q为正，容性负载Q为负。复功率的统一算法在下一小节展开。
2. 画出结点、端口和电压电流参考方向，区分已知与待求量。
3. 统一SI单位，使用与当前模型对应的元件关系。
4. 将公式按未知量整理后代入，保留中间结果以便回查。
5. 用原方程、初末极限或量纲核验，再解释符号。

<Example title="从相量得到P、Q、S">

**题目：** 关联方向U̇=100∠0° V，İ=2∠−30° A，求复功率和功率因数。

<Formula
  latex={
    "\\overline S=\\dot U\\dot I^*=100\\times2\\angle30^\\circ=173.205+j100\\,\\mathrm{VA}"
  }
/>
<Formula
  latex={
    "P=173.205\\,\\mathrm W,\\quad Q=100\\,\\mathrm{var},\\quad S=200\\,\\mathrm{VA},\\quad\\lambda=0.866025"
  }
/>

**核验：** 电流滞后电压，是感性，Q为正。复功率的模满足S²=P²+Q²；它是辅助计算量，不是随时间旋转的同频相量。

</Example>

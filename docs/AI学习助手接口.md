# AI学习助手接口预留

本轮只提供有类型的接入契约，没有上线模型调用或伪造助手回答。

`src/lib/assistant-contract.ts` 定义问题、知识点、教材出处、相关公式、解释与引用的请求/响应结构，以及可替换的 `LearningAssistantProvider.answer(request, signal)`。`learningAssistantContext(slug)` 只为有效知识页生成上下文。

下一阶段接入时，应在服务端实现提供者和API路由，密钥保存在服务端环境变量；前端不得持有密钥。返回引用必须指向实际知识页和教材来源，计算问题应优先调用已验证的计算函数。增加取消、超时、错误状态、速率限制和模型测试后再开放界面。

个人收藏、历史和学习记录默认不发送给外部模型。若未来需要个性化上下文，应向用户说明具体使用的数据并由用户选择。

# 电路方程自动生成器：实现与验收

日期：2026-10-15。入口：`/tools/equations`。

面向大学《电路》课程的直流线性电路教学工具。保留现有 Next.js App Router、React、TypeScript、KaTeX 与网站浅色/深色主题；没有添加运行时依赖。此前的界面原型已归档，本版从图纸实时计算拓扑、方程与结果，示例文件不包含预设答案。

## 使用流程

1. 打开“电路工具 → 电路方程自动生成器”，可直接修改默认分压电路，或点击“新建”。
2. 从左侧拖入电阻、独立电压源、独立电流源、接地，也可点击元件按钮后点击画板放置。
3. 点击端子开始连线，点击空白处添加拐点，点击另一端子、导线或地完成。Enter结束连线，Esc取消。T形端点连接；导线内部交叉只有添加实心连接点才连接。
4. 选中元件后在右侧修改名称、数值和单位，点击“应用参数”。旋转会带动已连接导线；反转极性/方向保持几何连接并反转该元件参考方向。
5. 选择自动、节点电压法或网孔电流法。快速答案集中展示方程、矩阵与结果；学习模式逐步展示参考节点、参考方向、列式、矩阵、消元与校验。
6. 使用“保存图纸”导出可恢复的JSON；“导入图纸”恢复编辑；“导出网表”获得SI单位的节点—元件数据。编辑后自动保存本机草稿，撤销/重做保留最近30次修改。

键盘：选择元件后方向键按网格移动，R旋转，Delete删除，W切换连线，Ctrl/Cmd+Z撤销，Ctrl/Cmd+Shift+Z重做。手机可点击放置、触摸操作和缩放、滚动画板。

## 功能与算法

| 模块 | 实现 |
| --- | --- |
| 图纸与网表 | `CircuitDocument`保留坐标、导线、连接点和地；`CircuitNetlist`保留节点、元件、SI参数及有序端子；几何与电气连接分开 |
| 节点识别 | 并查集合并相连端子、T形连接、重叠导线和显式连接点。所有地共享0V；未放地时按连接数量及坐标稳定选择参考节点 |
| 节点法 | 改进节点分析MNA：电阻电导、电流源注入、电压源电流未知量和电压约束。支持不接地的电压源 |
| 网孔法 | 通过平面图的有向边巡游识别内部面，建立顺时针网孔。含电流源时加入源电压未知量和电流约束，可处理公共支路电流源 |
| 独立回路 | 通过生成树与连支识别基本回路，单独展示KVL关系；不将任意基本回路冒充几何网孔 |
| 自动选择 | 无电流源的单网孔优先网孔法，其余优先通用节点法；显示选择理由，可手动切换 |
| 求解 | 行、列缩放和部分主元高斯消元，回代后恢复原单位。展示实际消元矩阵、缩放系数、节点电位、支路电压/电流/吸收功率、回代相对残差和总功率代数和 |
| 教学 | 方程符号与画板参考方向一致，解释KCL流入/流出、KVL正负号和电流源约束。关键步骤配原电路、节点及网孔图；矩阵与消元步骤配数学表达 |
| 可视化 | SVG电路符号、节点标签避让、网孔标记避让、教学图自动适配范围，手机画板局部滚动，公式和结果表局部滚动 |
| 错误处理 | 断开的子电路、未连接的地、矛盾电压源、欠定方程、非有限值及数值不可靠结果均显示诊断；不保留旧解。悬空端子按开路处理并提示 |

有序端子约定：电阻电流从端子1流向2；电压源端子1为正；电流源箭头从端子1指向2。支路电压均为端子1对2，功率采用关联方向。负电流说明实际方向相反，负功率说明发出功率。

## 验收方法与证据

- TypeScript、ESLint、生产构建通过，生成92个静态页面，包含`/tools/equations`。

- 全站50项浏览器回归全部通过（4.6分钟），包含目录滚动恢复、教材范围、公式检索、学习记录、旧计算器、全站图解遮挡和130组习题/正文例题的详细解答。

## 当前边界与扩展点

- 支持理想电阻、独立直流电压源和电流源；电阻必须为正，源可为零或负。电容、电感、受控源与交流/瞬态分析尚未实现，后续可扩展元件类型与矩阵盖章规则。
- 单张图纸最多40个元件、120条导线、1200个导线点、160个连接点和40个地；导入文件最大1MB。图纸结构和元件标识在导入及每次编辑时校验。
- 节点法可处理存在跨越导线的有效网络。几何网孔识别要求可辨认的平面绘图；无法识别时提示改用节点法或调整线路，不生成猜测网孔。
- 图纸与节点的编号随拓扑重新生成，显示端子—节点关系可用于核对。拥挤位置无法安全放置节点文字时保留拓扑面板中的节点身份。
- AI部分只预留`circuitLearningContext()`上下文，输出已验证网表、方程、步骤和结果；当前教学说明由确定性算法生成。没有AI聊天、付费模型请求或SPICE仿真服务。

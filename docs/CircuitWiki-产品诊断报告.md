# CircuitWiki 产品诊断报告

日期：2026-10-10。审查基线：`a98b61b`。本报告在修改应用代码之前完成。

## 1. 核心判断

CircuitWiki 已经是一套可运行、内容可信度有基础的电路学习资料库。距离长期使用的知识平台，主要差距在于：**知识关系没有成为系统数据，个人学习没有形成可回顾的空间，课程目录与学科知识体系尚未分离。**

建议定位为：**以电路理论为起点，连接概念、公式、图解、例题和个人学习记录的工程知识平台。** 当前服务大学电路学习与工程基础复习；模拟电子、数字电子、电力系统等领域逐步建设。站点对外展示必须对应真实可用内容。

“值得长期学习”来自准确内容、可解释的知识关系、稳定的个人记录和持续维护的证据。视觉负责让这些价值被理解。

## 2. 审查范围与证据

- 阅读 App Router 页面、MDX 编译、文章/教材/公式注册表、搜索、学习状态、组件、CSS 和浏览器测试。
- 实际检查首页、学习路线、节点电压法、第9章全览、公式速查、工具页，以及390px手机首页。
- 当前40篇MDX、53个教材小节索引、69条公式、3个独立工具；11个实际学习章节，章号保持教材约定。
- 浏览器快照和页面结构记录：`D:\codex\电路\work\product-audit\baseline`。
- Lighthouse 13.5.0，本机生产服务器、Edge、默认移动模拟及桌面预设。单次实验室测量，不能代表所有设备或公网体验。
- 没有访谈、真实流量、留存数据或真实搜索日志。本报告的用户痛点是基于任务走查的假设，后续需要用户验证。

## 3. 当前优势

1. **学科内容有锚点**：教材节号、公式条件、单位、代入示例、常见错误和电路图并置，适合建立工程直觉。
2. **交互与理论已经相连**：RC、相量、三相、多回路和端口实验提供即时反馈，具备区别于普通文章网站的基础。
3. **工程基础简洁**：Next.js静态知识页、本地可信MDX、严格KaTeX、SVG、纯计算函数与浏览器回归测试，部署路径稳定。
4. **基础使用闭环已存在**：按教材路线、公式筛选、全局快速搜索、最近阅读、手动完成标记、主题和移动目录已经实现，不应重复包装成新增功能。

## 4. 八项诊断

| 维度       | 现状与证据                                                                                                                                   | 用户影响                                               | 判断                                                               |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ | ------------------------------------------------------------------ |
| 产品定位   | 首页面向大学专业学生；新目标同时包括工程师和爱好者，当前内容仍是教材电路理论                                                                 | 不同背景的用户不确定适合从哪里进入                     | 保留明确内容边界，提供按目标选择的真实学习路径                     |
| 第一次访问 | 有开始学习、学习路线、工具入口；首页重复出现开始按钮，搜索依赖较窄的顶栏，缺少维护动态                                                       | 能进入，却难判断内容范围、更新情况与长期价值           | 强化知识地图、显著搜索、精选专题和真实更新记录                     |
| 学习路径   | 六阶段、11章、40页；只沿教材顺序，已学状态是自我标记                                                                                         | 复习者难选择短路径；标记完成不等于理解                 | 保留教材主线，增加基础入门/方法复习/交流专题路线，清楚标注学习目标 |
| 信息架构   | `chapters.ts`既决定内容归属又决定文章顺序；`Article`没有前置关系字段                                                                         | 不容易从“问题”进入对应概念，无法形成可计算知识图谱     | 分离“学科归属”“课程顺序”“概念关系”三种结构                         |
| 页面逻辑   | 相关知识主要在MDX正文末尾；右栏以页内目录和通用工具为主，`relatedTool`默认欧姆工具并将RL归给RC                                               | 阅读时无法及时补前置知识；部分工具推荐语义不精确       | 用结构化前置/后续/相关关系生成右栏；只显示真正适用的工具           |
| 功能缺口   | `StudyState`只有完成列表和最近slug；搜索只提供前8项、没有完整结果页和分类控件                                                                | 无法收藏、找回多篇历史或管理自己的学习资料             | 增加我的学习、收藏、历史、可迁移的本地记录及分类搜索               |
| 专业感     | 白底黑字、图示克制；不少元数据为10–11px，学习路线中检测到59个小于12px的文本节点；没有独立知识关系视图                                        | 密集小字不利长时间阅读，内容价值难被看见               | 建立字体、间距、状态、焦点和组件规范；工程感来自稳定层级与反馈     |
| 技术扩展   | 注册表分散；知识关系无验证；所有文章均`core:true`；CSS约3600行且含历史首页规则；学习记录未版本化；缺少canonical/OG/sitemap/robots/结构化数据 | 新领域扩展与统一修改成本增长，未来同步与AI接入缺少契约 | 有边界地补数据契约、校验、设计变量和SEO；保留现有MDX与静态架构     |

## 5. 用户痛点与任务

| 用户       | 具体任务                     | 当前卡点                           | 本轮解决方式                                |
| ---------- | ---------------------------- | ---------------------------------- | ------------------------------------------- |
| 大学新生   | 明确先学什么、哪里没懂       | 文章目录与概念依赖混在一起         | 推荐路线、前置知识提示、知识树              |
| 备考学生   | 在有限时间内复习分析方法     | 只能顺着40页查找；缺少收藏集合     | 方法复习路线、收藏、完整搜索                |
| 电气工程师 | 快速核对某个公式的条件与符号 | 快速搜索截断结果，知识关联不显眼   | 分类搜索、公式条件、关联知识与来源          |
| 电子爱好者 | 从一个电路现象理解原理       | 不清楚自己的前置知识缺口           | 入门路线、概念关系图、可操作图解            |
| 回访学习者 | 找回资料并继续学习           | 只能找最近一页，浏览器清理会丢记录 | 历史、收藏、本地导出/导入；暂不引入账户负担 |

以上任务需要后续与真实用户核对，不能据此宣称留存率或学习效果提升。

## 9. 本轮边界与实施顺序

1. 产品结构和布局：先建立知识数据与入口，保持原URL可用。
2. UI设计系统：统一变量与基础组件，改善阅读与状态表达。
3. 核心功能：知识关系、收藏/历史/进度、完整分类搜索、助手契约。
4. 性能与SEO：测量、优化、回归、部署。

每阶段在实施日志中列明原因、文件、内容和影响，并分别验证。沿用白纸黑字、教材顺序、戴维宁命名、既有章节范围和非重点标记。当前不把尚未撰写的模拟、数字、电力领域伪装为完整课程，不新增账户或复杂后端。

后续效果应通过“能否找到合适起点”“能否找到公式条件”“能否补上前置知识”“能否找回收藏/历史”四类任务验证，再考虑留存指标。单次自动评分和视觉审查不能证明世界级产品或教学效果。

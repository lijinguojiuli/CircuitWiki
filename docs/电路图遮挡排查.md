# 电路图标签遮挡排查与修复

日期：2026-10-11。

用户指出习题2-4(a)的a、Y被导线遮挡。原来的题目图把所有结点名统一放在结点正上方，竖直导线正好穿过字形。同图R₄的标签也贴近另一支路。

## 排查与结果

覆盖59个学习页、首页和工具页，展开解答后检查其中的插图，并检查12种多回路状态、4种桥臂端口状态、串联/并联的RL、RC、RLC相量图及各画图步骤。初始桌面截图扫描包含139种SVG视图，53种视图出现文字碰线、文字相叠或越出画布的候选；多个视图可能来自同一组件的不同状态。

审查同时使用浏览器实际字体包围盒、SVG变换矩阵和描边命中检测，并逐图检查截图。没有依靠白色遮罩覆盖导线；电路连接、数值、参考方向和计算结果保持原样。

修复后的全站回归分别在1440px浅色、390px深色下通过，覆盖默认图、展开解答中的图及上述交互状态，检查项为：文字不碰导线/元件边界、文字不互相重叠、不被SVG画布裁切、页面没有横向溢出。窄屏题目图继续支持容器内横向查看。

原有收藏、已学状态、阅读历史、章节结构及题目解答未改变。42项原内容与数值测试通过；新增3项全站图形浏览器检查通过，连同页面、工具及教材题回归共12项浏览器检查通过。Lint、TypeScript和生产构建通过，静态输出仍为91个。验收截图保存在`docs/screenshots/occlusion-*.png`，完整审查素材在`D:\codex\电路\work\diagram-audit`。

`src/app/challenges.css`同时调整了窄屏图形容器：横向滚动只移动电路图，图注和滑动提示保持可见，图形容器支持键盘聚焦。

## 重现方式

先启动网站，再在仓库目录运行：

```powershell
$env:PLAYWRIGHT_CHANNEL='msedge'
npm run test:e2e -- tests/browser/diagram-labels.spec.ts
$env:AUDIT_ASSERT='1'
node tests/audit-diagrams.mjs
```

可以用`AUDIT_ORIGIN`检查部署后的地址，用`AUDIT_WIDTH`和`AUDIT_THEME`改变截图尺寸与主题，用`AUDIT_OUTPUT`指定项目目录内的审查输出位置。

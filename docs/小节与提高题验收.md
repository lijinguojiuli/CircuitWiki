# CircuitWiki 小节与提高题验收

日期：2026-10-11。对应本次“移除章节全览、每个学习小节独立成页、增加难题”的修改。

## 内容和学习入口

- 53 个实际学习的教材小节独立成页，名称、章号和节顺序沿用用户确认的邱关源《电路》第5版。
- 原 11 篇章节聚合讲解已经拆到对应小节；目录、知识体系、学习路径和搜索不再提供聚合文章入口。
- 另保留 6 篇补充专题：桥臂一端口、诺顿、RC、RL、功率因数、RLC。它们与教材小节关联，不重复计入学习路线的53节。
- 每节均包含概念、前置知识、公式与用法、步骤、图解、综合题、易错点和相关知识。
- 每节一道原创多问综合题，共53题：38道综合提高、15道综合挑战。保留基础数字示例用于解释公式，原简单选择测验已从文章移除。
- 新增 `/practice`，可按教材章节和题目类型筛选；全局搜索可以定位提高题。
- 提示和解答默认折叠。解答提供独立方程、计算过程、最终结果和适用条件。

例如：不平衡电桥的两种解法、三网孔与共享电流源、超级结点与受控源、负输入电阻、戴维宁的两种端口计算、效率约束下的最大功率、两次换路与过零时间、耦合回路联立求解、非理想线圈并联谐振、不对称三角形及Y/Δ混合负载。

## 既有范围与约定

本次没有扩大约定的学习范围：第4章§4-1至§4-4，第7章§7-1至§7-4，第10章保留互感与耦合内容、变压器仅含理想模型，第11章仅串联和并联谐振；第5章及二瓦计法不进入学习入口。学习目录不显示跳过提示。

RC、RL时间常数分别使用 `Req C`、`L/Req`。中性点位移、并联电容补偿继续标记“非重点”。名称统一为“戴维宁”。矩形电阻、教材电源符号、结点处接地、黑白浅/深色主题继续保留。

## 来源与质量检查

题干、数值和本站解答为原创，不冒称教材原题或考试真题。教材用于知识范围与记号对齐。提高题页另外提供两份公开课程原题链接，供比较解题组织；不把这些外部原题计入53题：

- [MIT 6.002 Homework 2](https://ocw.mit.edu/courses/6-002-circuits-and-electronics-spring-2007/15878f74dcca61c4298c957999778bc0_hw2.pdf)：多结点与端口互联。
- [MIT 6.301 Problem Set 1](https://www.ocw.mit.edu/courses/6-301-solid-state-circuits-fall-2010/e48c1f9b07de7925b7864952954f0ff3_MIT6_301F10_assn01.pdf)：第3题的含受控源输入电阻。

独立数值检查覆盖线性/复数方程残差、图的回路关联、星三角关系、功率、积分能量、储能、一阶响应、复功率与谐振条件。全部53题的步骤与最终答案通过严格KaTeX渲染检查。数值检查不能代替人工审题，因此额外核对电桥、三网孔、超级结点和戴维宁题的电源极性、结点与支路连接图。

## 当前限制

每节目前一套综合题，尚无多套随机练习、作答自动评分或考试模式；题目的难度标签是编辑分级，未用学生答题统计校准。本地收藏和学习记录无需登录，仍不自动跨设备同步。此次未重新测量Lighthouse，既有性能报告属于此前版本；浏览器验收使用Edge Chromium，未声明已验证Firefox、Safari或实体手机。

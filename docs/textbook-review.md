# 第5版教材校对记录

用户已确认采用所提供的《电路》第5版（邱关源原著，罗先觉修订，2006年）。PDF 共588页，书页与 PDF 页序的对应关系为：PDF 页序 = 书页 + 19；封面在 PDF 第1页，版权信息在第3页。

## 已完成

- 16 篇知识页的核心公式、符号解释与数字示例记号已逐项核对并调整；核心公式标出书页与式号，原创代入示例按相同记号计算。
- 电压源按 p.16 图1-8：轴向纵线、外侧极性。电流源按 p.18 图1-10：横向直线、外侧电流箭头。直流源使用 US、IS，交流激励使用 uS；下标通过 SVG tspan 渲染。
- 结点方程改用 uₙ、书中自导/互导与注入电流记号，明确互导为负，避免重复减号。
- 网孔变量使用 iₘ；本站双网孔图是书中式（3-6）的 uS2=0 特例。
- 戴维宁/诺顿参数统一为 uoc、isc、Req；本站题名“戴维南”保留常见译法，注明书中题名。
- 储能为 WC(t)、WL(t)；RC 输入为 US，三要素通式使用 f；相量使用点号，复功率使用横线。
- 公式速查和 RC/欧姆工具已同步公式、适用条件与教材出处。
- 按用户最新要求移除圆圈内 A/V 的仪表图、对应组件和接法示意，保留教材电源符号及电源约束易错提示。

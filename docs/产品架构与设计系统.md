# CircuitWiki 产品架构与设计系统

## 产品流程

发现知识 → 选择路线 → 阅读/图解/公式/例题 → 实验验证 → 收藏/标记/回顾 → 沿知识关系继续学习。

## 站点结构

```text
/                         首页：定位、搜索、推荐路线、精选知识、最新内容更新
/knowledge                知识体系：学科 → 主题 → 概念
/curriculum               教材学习路线：原有章号、节号和文章顺序
/paths                    按学习目标选择的推荐路线
/paths/[slug]             路线目标、前置要求、课程序列、路线进度
/learn/[slug]             知识页：内容、关系、公式、个人记录
/graph                    可选择中心知识点的局部关系图与文本列表
/search                   关键词/公式/类型/分类搜索
/formulas                 公式手册
/tools                    电路实验与计算
/me                       我的学习：收藏、历史、已学、本地记录备份
```

首层导航突出“知识体系 / 学习路线 / 公式速查 / 工具”，个人入口单独显示“我的学习”。知识图谱归入知识体系，也从文章关联区进入，避免顶栏堆积。

## 知识树与课程的区别

学科树表达内容归属；教材章节表达教学顺序；有向前置关系表达依赖。三者使用同一个稳定slug引用文章，不能通过标题文本匹配维持关联。

```text
工程知识
├─ 电路理论（当前内容）
│  ├─ 电路语言：参考方向、元件、KCL/KVL
│  ├─ 等效与分析：星三角、输入电阻、节点/网孔、电路定理
│  ├─ 储能与动态：电容、电感、一阶响应
│  ├─ 相量与交流：复数、正弦量、阻抗、相量图、功率
│  ├─ 耦合与谐振：互感、同名端、理想变压器、谐振
│  └─ 三相电路：Y/Δ、线相关系、计算与功率
├─ 模拟电子技术（内容建设后开放）
├─ 数字电子技术（内容建设后开放）
└─ 电力系统（内容建设后开放）
```

未开放领域只说明建设边界，不作为可学习课程计数，也不进入现有教材路线。后续可以追加电力电子和嵌入式分支。

## 知识页面

- 左栏：现有教材目录与位置保留；切页保持目录滚动。
- 正文：标题、出处、收藏、阅读进度、前置提示、八节MDX、关系回顾、完成标记、上一篇/下一篇。
- 右栏：页内目录、前置/后续/相关知识、本章公式入口与真正适用的实验。
- 手机：目录与关系可折叠；所有知识关系都有文本链接，不要求操作复杂图形。
- 阅读百分比表达阅读位置，完成标记表达用户自我记录，两者独立。

## Design System

| 系统          | 约定                                                                                          |
| ------------- | --------------------------------------------------------------------------------------------- |
| 色彩          | 白/近白阅读面、黑色正文、可读灰色辅助文字；深色使用同一语义变量；颜色不承担唯一状态含义       |
| 字体          | 系统无衬线中文字体，正文16px、行高1.9；元数据12–13px；数学沿用KaTeX，电路标注沿用教材习惯     |
| 间距          | 4/8/12/16/24/32/48/64px；正文行宽优先，章节有稳定间隔                                         |
| 边界          | 1px边框、6–10px圆角，强阴影仅用于浮层；避免卡片套卡片                                         |
| Button        | primary/secondary/ghost，sm/md；明确hover、focus、disabled、pressed；链接与动作分别用a/button |
| Card          | 内容容器与可导航卡片分开，标题和描述层级统一                                                  |
| Tag           | 内容类型、章号、非重点；不改变科学含义                                                        |
| Code Block    | 等宽字体、可横向滚动、深色可读，代码与正文分开                                                |
| Formula Block | LaTeX、条件、符号、单位、来源；长式局部滚动，页面不溢出                                       |
| Diagram Block | 响应式SVG、语义标题、教材符号、caption；保持电阻长方形与电源画法                              |
| Alert         | tip/important/warning；图标、标题和内容表达状态，避免只靠颜色                                 |
| 可访问性      | 可见焦点、原生表单标签、44px主要触控区域、减少动态效果；空状态给出下一步                      |

## 数据与技术边界

- 文章与MDX沿用现有来源；新增知识归属与依赖数据，自动推导后续知识和关联引用。
- 版本化个人记录保留旧完成数据，新增收藏、历史与阅读位置；本地存储，无账号；可导出/导入JSON并校验。
- 搜索共用同一索引，快速浮层只做入口，完整页提供分类与类型筛选。
- 更新日志使用真实维护条目；“热门”在无访问统计时明确为编辑精选。
- AI预留问题、知识点、引用公式与教材来源的请求/响应契约，不把客户端放入API密钥。
- 页面静态生成优先，交互按客户端岛拆分；数学在服务端渲染，图表按需要加载。
- SEO使用稳定canonical、Open Graph、站点地图和面包屑结构化数据；个人页与搜索页不索引。

## 分阶段验证

每个阶段先报告修改原因、文件、内容和影响，再执行。结构数据验证无遗漏/无环/无死链；个人数据验证迁移、刷新、跨标签同步与损坏输入；视觉验证桌面、手机与深色；最后运行lint、类型、内容、浏览器、构建以及同条件Lighthouse前后测。
